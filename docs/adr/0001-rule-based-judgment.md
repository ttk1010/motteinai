# ADR 0001: 判定はルールで行い、AIはタグ付けだけに使う

- Status: Accepted
- Date: 2026-11-04

## Context

買う前チェックでは「買い／保留／見送り」と、その根拠（`似ている 87%`、`＋12通り`）を数秒で見せる。根拠が毎回変わったり説明できなかったりすると、店頭で信用されない。

## Decision

似ている度合い・相性・＋N通り・判定は `src/shared/engine.ts` の決定的なルールで計算する。AI（Workers AI）は「写真 → タグ」だけを担当する。判定の理由も、数字を並べたラベルで出す。

## Consequences

- 同じ手持ちと同じ服なら、いつも同じ判定と数字になる。テストで固定できる
- AI が遅い・失敗しても、タグさえあれば判定は出る。タグは確認待ちで手で直せる
- 「おしゃれかどうか」のような主観は判定に入らない。色・柄・きちんと度・シルエットで表せる範囲に限られる

## Alternatives considered

- **判定まで LLM に任せる**：理由を自然文で書けるが、同じ服でも答えが揺れ、数字の根拠を示せない
- **画像の埋め込み（ベクトル）で似ている度合いを出す**：Workers AI に画像の埋め込みモデルが見当たらず、属性ベースで十分に効いた
