# Roadmap

## Phase 1 — MVP ✅

- 連続撮影の登録、写真・URL・共有メニューからの取り込み
- 背景の切り抜き、AI のタグ付け、確認待ち
- 買う前チェック（判定・＋N通り・似ている手持ち・合う手持ち）
- 買うと良い服、買い物リスト、気になるリスト
- 今日のコーデ（天気・出番のない服）、着た記録
- Google ログイン、データの書き出し、アカウント削除
- Cloudflare の無料枠で公開（GitHub Actions で自動公開）

## Phase 2 — 本番で使い込む（次）

- [ ] 本番の Workers AI で、タグの精度と1着あたりの Neurons を測る
- [ ] EC のモデル着用写真から、服の部分だけを切り出す
- [ ] ログインのライブラリ（Arctic、配布元でサポート終了）を自前の実装に置き換える
- [ ] GitHub Actions を Node.js 24 対応の版に上げる
- [ ] 誤判定の例を集め、判定ルールの重みを調整する

## Phase 3 — 公開して人に使ってもらう

- [ ] プライバシーポリシーのページを追加し、Google の「アプリを公開」を行う
- [ ] 独自ドメイン（カスタムドメイン）の検討
- [ ] 1枚の写真から複数の服を切り出す

## 後回し（MVP の範囲外）

- Eレシート・注文履歴の取り込み
- 体型・肌色に合わせた提案
- 他の人との共有、旅行の荷物リスト、カレンダーで先の予定を組む
